# DoctaRx scope and acceptance ledger

Reviewed 14 October 2026 against the user's full instructions, the revised master prompt, implementation plan, current source and recorded evidence. This is the current scope contract for the main DoctaRx platform and CareOps. It supersedes historical whole-product “VERIFIED COMPLETE” labels and PHC-first sequencing. No requirement is considered complete merely because a route, shell, build, or source-contract test exists.

Implementation is tracked in draft [PR #11](https://github.com/Jonahbaka/zuma-teledoc/pull/11). The recorded main-platform changes passed local lint, tests, isolated database checks and production build, with bounded existing-account browser evidence described below. Remote checks must be evaluated on the PR's current head; earlier green commits do not validate subsequent changes. The delivered validation report records the exact revision and CI outcome when available.

## Explicitly deferred expansion

Keep these visible in the roadmap rather than implying that Teladoc/Solo benchmarking delivered them: asynchronous specialist image-case lifecycle, ambient scribe/audio capture, camera-derived vital signs and fall-risk detection, approved connected devices/CGM/remote monitoring alerts, full PACS, native mobile applications, and additional PHC programmes. A prescription photo upload is not an asynchronous dermatology consultation.
